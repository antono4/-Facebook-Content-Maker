# Facebook Content Maker

> **Created by Antono** | 🇮🇩 Indonesia

A web application for creating Facebook content with ease.

## ✨ Features

- 📝 Create engaging Facebook posts
- 🎨 Design graphics for social media
- 📱 Mobile-responsive interface
- 🔄 Easy to customize

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/antono4/-Facebook-Content-Maker.git

# Navigate to the project
cd -Facebook-Content-Maker

# Open in browser
open index.html
```

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
